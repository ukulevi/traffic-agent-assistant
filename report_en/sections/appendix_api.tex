\chapter{Full REST API Specification}

\section{Overview and Authentication}
The STWI HTTP Gateway exposes an OpenAPI 3.1 compliant asynchronous REST API. All endpoints enforce bearer token authentication and tenant boundary isolation.

\subsection{Endpoint Summary}
\begin{itemize}[leftmargin=1.5cm, label=$\bullet$]
  \item \textbf{\texttt{POST /api/v1/what-if-jobs}:} Ingests a new simulation job. Returns HTTP 202 Accepted.
  \item \textbf{\texttt{GET /api/v1/what-if-jobs/\{job\_id\}}:} Retrieves current job status and full result payload.
  \item \textbf{\texttt{GET /api/v1/what-if-jobs/\{job\_id\}/events}:} Server-Sent Events (SSE) stream broadcasting real-time progress events.
  \item \textbf{\texttt{GET /api/v1/health}:} Health check endpoint returning service status.
\end{itemize}
