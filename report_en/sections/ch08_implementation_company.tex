\subsection{Engineering Culture and Quality Assurance}
The engineering division adheres to high professional standards:
\begin{itemize}[leftmargin=1.5cm, label=$\bullet$]
  \item \textbf{Agile/Scrum Framework:} Bi-weekly sprints, daily 15-minute standup meetings, sprint planning, and retrospective reviews.
  \item \textbf{Mandatory Code Review \& CI Gates:} Every code change is submitted via Pull Request and must pass automated unit tests, linting (PEP 8, ESLint), and architectural invariant checks before merging.
  \item \textbf{Cloud \& On-Premise Infrastructure:} VNPT Cloud ecosystem combined with on-premise GPU clusters, real-time telemetry, and Docker Compose containerization.
  \item \textbf{Data Privacy \& Compliance:} Strict adherence to NDA agreements, data anonymization, and the Zero Raw-Video Retention principle.
\end{itemize}
